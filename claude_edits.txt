3. MOSAIC EDITOR FIX — "No module named 'loky'"
-------------------------------------------------------------------------------
Cause:
  acq4/analysis/modules/MosaicEditor/MosaicEditor.py imports loky at module
  top (lines 31-32):
      from loky import get_reusable_executor
      from loky import wrap_non_picklable_objects
  The decorator @wrap_non_picklable_objects on operate_on_item() (line 40) is
  live, so the import runs unconditionally. loky was never declared in
  pyproject.toml, so a fresh `uv sync` never installed it -> ImportError broke
  the whole module.

Fix:
  Added "loky" to [project].dependencies, then `uv lock` + `uv sync`.
  Resolved: loky 3.7.0 (+ transitive cloudpickle 3.1.2). Package count 86 -> 88.

Note for later:
  Only @wrap_non_picklable_objects is currently used; the parallel executor
  path using get_reusable_executor (MosaicEditor.py ~lines 615-620) is still
  commented out, and the active path runs serially. loky is therefore an
  effectively decorative dependency until the parallel work is finished. If
  that work is abandoned, the two imports + decorator + the loky dependency
  can be removed instead.
